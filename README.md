## Overview

College Admissions Roadmap is a free, interactive textbook that walks high school students through the
whole college application process, from building a first college list in the summer before senior year to
move-in day the following fall. It's written to the student, but works just as well read alongside a parent,
guardian or school counselor, and it assumes no prior knowledge, so first-generation students can follow
every step.

The book's 20 chapters follow the order of senior year: how admissions works, building and researching a
list, getting organized, the SAT and ACT, senior-year courses, activities, the personal and supplemental
essays, recommendations, the Common App, interviews, financial aid, scholarships, award letters, waiting,
decisions, the final choice and the summer before college. A fictional senior, Priya, works through each
step as a running example, and the book closes with a complete application roadmap for one real school, the
University of Iowa.

What makes it an *intelligent* textbook is that it's built on a learning graph of 342 concepts and their
prerequisites, and it's interactive. Fifty MicroSims let students try the ideas with their own numbers:
calculate a GPA, plot a test score against a college's middle 50% range, sort a balanced college list,
decode an award letter or compare final choices side by side. Every chapter also has a quiz and annotated
references, and the book includes a glossary and FAQ.

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/bakullberg/College-Admissions-ebook.git
cd College-Admissions-ebook
```

### Install Dependencies

The site is built with MkDocs and the Material theme:

```bash
pip install mkdocs mkdocs-material
```

### Build and Serve Locally

Check the site for broken links and missing pages:

```bash
mkdocs build --strict
```

Serve it locally with live reload:

```bash
mkdocs serve
```

Then open `http://127.0.0.1:8000/College-Admissions-ebook/` in your browser.

### Deploy to GitHub Pages

```bash
mkdocs gh-deploy
```

This builds the site and pushes it to the `gh-pages` branch.

### Using the Book

- Use the left sidebar to browse chapters. Each chapter opens to its **Content**, **Quiz** and
  **Annotated References**.
- Use the search bar at the top of every page to find any term.
- Find every MicroSim on the **MicroSims** page. Each one runs in the browser, with no installation needed.
- Look up any term in the **Glossary**, or browse the **FAQ** for quick answers.

### Building the PDF Manuscript

The repository also contains the original manuscript, which builds to a designed PDF with a cover, table of
contents and PDF bookmarks:

```bash
python3 -m pip install --user reportlab markdown pypdf
python3 scripts/build_pdf.py
```

The script reads the Markdown in `manuscript/` and rebuilds `dist/College-Admissions-Roadmap.pdf` from
scratch, including the table of contents and page numbers.


## Reporting Issues

Found a mistake, an out-of-date policy or a MicroSim that doesn't work? Please report it on
[GitHub Issues](https://github.com/bakullberg/College-Admissions-ebook/issues).

Admissions and financial aid policies change every year, so reports of outdated dates, deadlines or rules are
especially welcome. When reporting, please include:

- The page or MicroSim, with a link if possible
- What you expected and what you saw
- A screenshot, if it helps
- Your browser, for MicroSim problems
