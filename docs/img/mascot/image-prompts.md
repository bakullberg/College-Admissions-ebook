# Image Prompts: Scout the Turtle

I am about to ask you to generate seven different poses for a book mascot.
Please use a consistent drawing style for all seven images.

Paste the prompts below one at a time into your AI image tool (ChatGPT, Gemini or similar), in the same conversation so the style stays consistent. Each prompt is complete on its own. Save each image with the filename shown, into `docs/img/mascot/`, replacing the placeholder file.

## 1. Neutral

```text
Please generate a new pose for Scout the Turtle.
A modern flat vector cartoon illustration of Scout the Turtle, a friendly pedagogical mascot for a college admissions textbook for high school seniors. Scout has soft sea green skin (#6BAF92) and an indigo shell (#3F51B5) with lighter indigo hexagon plates, wearing a loosely knotted orange scarf (#FF9800) and a small round brass compass hanging from a cord around the neck. Scout has calm, warm eyes and a gentle, reassuring smile. The character is small and compact, standing upright on the back legs, suitable for icon-sized display.
Style: modern flat vector cartoon, clean lines, solid colors, transparent background with alpha channel, suitable for embedding in educational content. No text in image.

Scout stands upright in a relaxed, neutral pose facing the viewer directly, with a calm and friendly closed-mouth smile. Front legs rest naturally at the sides with no specific gesture. The pose is balanced and unassuming — suitable as a general-purpose or default illustration.
Filename: neutral.png

Please generate a new RGBA PNG image now with a fully transparent alpha-channel background.
The background MUST be fully transparent with an alpha channel. DO NOT use a white, black or a checkered background.
```
