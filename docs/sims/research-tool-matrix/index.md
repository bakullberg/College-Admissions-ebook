## About This MicroSim

Show students which college research tool best answers which question, so they can choose the right tool instead of relying on one source for everything.

**Learning objective:** Students will select the research tool best suited to a given question about a college and differentiate between data tools and experience tools.

This MicroSim supports [Chapter 4: Researching and Narrowing Your College List](../../chapters/04-researching-your-list/index.md).

## How to Use

- Each circle shows how well a tool answers a question: filled = strong, half = partial, empty = weak (illustrative ratings).
- Click any circle to read why, with a tip for using that tool.
- Click a column header, or pick a question in **I want to know...**, to highlight the best tools for it.
- Press **Quiz me** for a random question, then click the tool you'd use. On narrow screens, use **Previous tool** and **Next tool** to flip through the tool cards.

## Lesson Plan

### Learning Objective

Students will select the research tool best suited to a given question about a college and differentiate between data tools and experience tools.

**Bloom level:** Analyze (L4) — select, differentiate

### Audience

High school juniors and seniors, and the parents, counselors, and mentors helping them.

### Duration

10 minutes

### Prerequisites

Read the section of [Chapter 4](../../chapters/04-researching-your-list/index.md) that introduces this MicroSim.

### Activities

1. **Data or experience? (3 min):** For each question, decide whether it is a numbers question or an experience question before you look at the matrix.
2. **Quiz (4 min):** Answer five quiz questions in a row without a miss.
3. **Plan your research (3 min):** Write down one question you have about a college on your list and the two tools you'll use to answer it.

### Discussion Questions

- Why is a neutral source like the College Scorecard useful even when a college's own website has the same number?
- Which questions can't any data tool answer well?
- How should you use student reviews that anyone can post?

### Assessment

Students choose the strongest tool for five different questions and explain the difference between data tools and experience tools.
